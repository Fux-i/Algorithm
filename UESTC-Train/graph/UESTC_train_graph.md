## A. Dijkstra

一个标准的 Dijkstra 算法。主要思想如下，节点数和边数分别为 $n, m$：

1. 用一个`dis`数组维护起始节点到每个点的距离，初始时为无穷大（`dis[s] == 0`）
2. 对所有节点进行一次“松弛”操作，优先选择距离起始节点最近的那个，用小顶堆维护
3. 每次“松弛”操作比较该节点 $u$ 到 $s$ 的距离加上 $u$ 到下一个节点 $v$ 的距离，与`dis[v]`相比，若前者更小，则更新`dis[v]`，并将`dis[v]`对应的节点入堆

这样所有节点“松弛”一次后，`dis[v]`就表示 $s$ 到 $v$ 的最短距离。时间复杂度为 $O(m\log m)$

## C. Construction + Dijkstra

一句话题意：有 $n$ 个点，标号 $0 \sim n-1$，$i$ 号点有一个权值 $a_i$，表示从 $i$ 号点可以一秒跳到 $(i+a_i)\mod n$ 号点，
每秒可以选择跳，也可以选择将当前点的 $a_i$ 永久加一，求从 $0$ 到 $x$ 所需的最短时间。

思路：将原来的数组视作 $A$，再新增一个数组 $B$，原先的`跳跃`操作视为从 $A(i)$ 跳到 $B(i+a_i)$，$a_i$ 永久加一视为从 $B(i+a_i)$ 跳到 $B(i+a_i + 1)$，$B(i)$ 到 $A(i)$ 视为落地

```cpp
auto A = [&](int i){ return i; };
auto B = [&](int i){ return n + i; };

for(int i = 0; i < n; ++i){
    int d = (int)(((long long)i + a[i]) % n);
    g[A(i)].push_back({B(d), 1});
    g[B(i)].push_back({B((i + 1) % n), 1});
    g[B(i)].push_back({A(i), 0});
}
```

## H. Tarjan · SCC

题目大意：在简单有向图中，求最少需要加多少条边，才能使从 $s$ 开始可以到达所有节点

思路：用 $Tarjan$ 算法将所有强联通分量缩为一个点，随后统计入度为 0 的点的个数，若 $s$ 入度也为 0，答案减 1
